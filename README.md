# MathSlash

Slash the right answer. A mobile-friendly swipe math game for addition, subtraction, multiplication, and division.

Pick an operation, a difficulty, and (for × / ÷) a times table. Three lives. Combos multiply your score. Best scores stay on the device.

## Run it

```bash
npm install
npm run dev
```

Then open the printed local URL. Swipe through the fruit with the correct number.

```bash
npm run build
npm run typecheck
```

## Stack

React 19, TanStack Start, Vite, Tailwind v4, Zustand, Canvas 2D.

Fruit is the current skin. The name is MathSlash so the theme can change later without a rename.
