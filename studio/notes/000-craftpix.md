## Start with these

**Beach:** [Free Beach 2D Game Backgrounds](https://craftpix.net/freebies/free-beach-2d-game-backgrounds/)
- 2D cartoon vector. 4 themed beaches, PNG 1920×1080 landscape, plus 22 layered parts, AI/EPS.
- Sand, water, sky. Quiet enough that flying numbers stay readable.
- No portrait file. Vector layers mean we crop/scale one landscape into a phone frame without a second pack.

**Balloons:** there is no free Craftpix water-balloon pack. Closest start is already on disk from PipTales:
- [Free Underwater World 2D Game Objects](https://craftpix.net/freebies/free-underwater-world-2d-game-objects/) — `Bubble_1.png`, `Bubble_2.png`, `Bubble_3.png` at `/workspace/piptales/public/assets/craftpix/underwater-2d/PNG/Neutral/`
- 2D glossy round water orbs (teal / blue / purple). Big friendly number stamps cleanly in the middle. Tint in canvas to beach-toy colors. Not a tied rubber balloon, but it reads as water.
- Pair the pop with [Free Water Effects Sprite Pack](https://craftpix.net/freebies/free-water-effects-sprite-pack/) (2D PNG/PSD, 10 splash / drop / geyser anims). Download that only after David picks.
